Google Drive

Para subir/cargar el JSON de socios necesitas un Client ID de Google Cloud (tipo «Aplicación web»). Solo se usa en este navegador.

  1. En Google Cloud → Credenciales crea un ID de cliente OAuth 2.0.
  2. Tipo: Aplicación web. En orígenes JavaScript autorizados añade la URL desde la que abres esta página (p. ej. http://localhost:8080).
  3. Activa la API «Google Drive API» en la biblioteca.
  4. Pega aquí el Client ID y guarda.

🌐 Publicar en la web

La página contiene fichas de socios. Para protegerlas, solo se permite publicar en un repositorio privado con GitHub Pages de acceso restringido.

Para un destino privado, utiliza un token limitado al repositorio de destino con permisos de lectura de Pages y escritura de contenido. No se guarda al recargar la página.
